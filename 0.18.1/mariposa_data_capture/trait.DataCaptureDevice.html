fn new_file( &self, descriptor: FileDescriptor, ) -> Result<DataCaptureFileBuilder, DataCaptureError>

Create a new file for capturing data, via a builder. The file will start disabled. You must call start() to start it. This allocates length bytes on the device and returns an error if there is not enough space.
