Struct MapIter 

Source 
pub struct MapIter<I>(/* private fields */);
Expand description

An encodable iterator writing its items as a CBOR map.

This type wraps any type implementing [Iterator] + [Clone] and encodes the items produced by the iterator as a CBOR map.
