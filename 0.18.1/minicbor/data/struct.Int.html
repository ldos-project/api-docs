Struct Int 

Source 
pub struct Int { /* private fields */ }
Expand description

CBOR integer type that covers values of [-264, 264 - 1]

CBOR integers keep the sign bit in the major type so there is one extra bit available for signed numbers compared to Rust’s integer types. This type can be used to encode and decode the full CBOR integer range.
