Expand description

A combined trait for block devices that support I/O performance tracing.

This trait combines BlockDevice (basic block I/O operations) with BlockIOObservable (I/O performance trace queues), enabling policies like LinnOSPolicy to observe completion traces for intelligent device selection.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
