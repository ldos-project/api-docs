Macro path 

Source 
macro_rules! path {
    ($($part:tt)*) => { ... };
}
Expand description

Creates a new Path from . (dot) delimited literal. The syntax is a series of segments which are either a name, like a, or a name and index, like b[5]. The index can be replaced by {expr} to set the index at runtime. The index can also be replaced by the keyword unique to generate a new unique number for each invocation of this path! invocation. If there are multiple identical path! invocations in the program, they will produce duplicate indexes. Internally, the unique index is generated by an static atomic counter local to the macro call site.

The returned path will be as static as possible and does not require parsing at runtime.

§Examples

let path = path!(a.b[3].j);
assert_eq!(path.to_string(), "a.b[3].j");
let index = 42;
let path = path!(x[unique].n[{index}]);
