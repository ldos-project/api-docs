pub fn register<T: Copy + Send + Serialize + 'static>(
    path: &Path,
    oqueue: &GenericAnyOQueueRef<LifetimelessElementDescriptor<T>>,
)
Expand description

Registers an OQueue at path and exports it to userspace with the message type’s derived Serialize implementation (the whole message is streamed).

This is the common case for exportable queues: the message type just needs #[derive(Serialize)] (plus Copy, since the whole value is observed). Use register_with_projection to provide a projection, register_with to use the message type’s DefaultProjection, or register_no_export for queues that must not be exported.
