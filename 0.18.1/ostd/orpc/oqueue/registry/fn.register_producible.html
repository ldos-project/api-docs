Function register_producible

pub fn register_producible<T: Copy + Send + Serialize + DeserializeOwned + 'static>(
    path: &Path,
    oqueue: &ConsumableOQueueRef<T>,
)
Expand description

Registers a super::ConsumableOQueue at path and exports it to userspace for production and consumption: a userspace writer can attach a producer (e.g. via the OQueue filesystem’s produce file) and send values of type T into the queue by writing their CBOR encoding, and a userspace reader can attach a consumer.

Unlike register, register_with, and register_with_projection, this is for produce and consume in userspace; only a ConsumableOQueueRef can be passed.

§Panics

Panics if a live export already exists at path.
