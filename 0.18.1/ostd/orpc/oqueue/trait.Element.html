An element which can be placed in an OQueue. This trait should always be handled by a generic impl or derived.

Required Associated Types§

Source

type Descriptor: ElementDescriptor

The descriptor for this element type.

For many types this will be LifetimelessElementDescriptor<Self>. For types with lifetime parameters, this will be a special descriptor type which carries the universally quantified element type as Element.

Dyn Compatibility§

This trait is dyn compatible.
