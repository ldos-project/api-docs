Trait ElementDescriptor

pub trait ElementDescriptor: 'static {

Expand description

A trait for types which encapsulate a element type Self::Element. This wrapper is required for types with lifetime parameters. You should never have to implement this trait yourself. It will be generated automatically if you derive Element.

Most normal types can use LifetimelessElementDescriptor<T>.

This type cannot be replaced with Self::Element itself, because that takes a lifetime parameter and Rust does not support passing type universally quantified types as type parameters.

As an example, consider the example from the oqueue module.

ⓘ
struct Args<'a> {
    self_: &'a Self,
    buf: &'a [u8],
    n: usize
}

has the descriptor:

ⓘ
struct ArgsDescriptor {
    type Element<'a> = Args<'a>
}
