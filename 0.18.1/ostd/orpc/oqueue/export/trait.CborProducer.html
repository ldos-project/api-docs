Expand description

A per-reader handle that accepts CBOR-encoded bytes from userspace and produces the decoded values into an OQueue, with the message type erased.

Required Methods§

Source

fn produce_cbor(&self, bytes: &[u8]) -> Result<usize, ProduceCborError>

Attempts to decode one CBOR-encoded record from the front of bytes and, if complete, blocks (if necessary) until there is space to produce it into the OQueue.

Returns the number of bytes consumed from the front of bytes on success. Returns Ok(0) if bytes does not yet contain a complete record (the caller should append more bytes and retry). Returns Err if bytes starts with malformed CBOR, if the CBOR item does not decode as the expected message type, or once the underlying OQueue is gone.

Source

fn can_produce(&self) -> bool

Returns whether Self::produce_cbor would currently not block on a complete record. This is a hint: other attachments may change the OQueue immediately afterwards.

Source

fn on_ready(&self, hook: Box<dyn Fn() + Send>) -> WakeHook

Registers hook to be called when Self::produce_cbor may stop blocking, until the returned WakeHook is dropped. The hook may be called even though a produce would still block, so treat it as a prompt to retry.

§WARNING

hook must be fast and non-blocking: it is called with a lock held and interrupts disabled. See ValueProducer::on_ready.
