Expand description

A message-type-erased handle to an OQueue that has been exported for userspace consumption.

Stored in the export registry so consumers can enumerate and read queues by Path without naming the message type. An export can independently carry an observe attachment, a produce attachment, and a consume attachment: register / register_with add an observe attachment, and register_producible adds a produce attachment and a consume attachment. This is a factory: attaching mints a fresh per-reader (or per-writer) handle.

Attaches a fresh observer and returns it as a CBOR record source.
