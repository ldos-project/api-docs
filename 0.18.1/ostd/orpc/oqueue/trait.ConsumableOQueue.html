Expand description

An OQueue for communication which support producing by value and consumers.

Required Methods§

Source

fn attach_value_producer(&self) -> Result<ValueProducer<T>, OQueueError>

Attach a producer to the queue which will use it for communication by moving messaged into the OQueue.

Source

fn attach_consumer(&self) -> Result<Consumer<T>, OQueueError>

Attach a consumer to the queue which will receive ownership of each message that is produced.

Source

fn produce(&self, v: T) -> Result<(), OQueueError>

Produce a value, giving up ownership. This is used to pass an object to the consumer.

Source

fn try_produce(&self, v: T) -> Result<(), TryProduceError<T>>

Try to produce a value without blocking. Returns Err(NoSpace(v)) if the operation would block or Err(Error(e, v)) if there was an error.
