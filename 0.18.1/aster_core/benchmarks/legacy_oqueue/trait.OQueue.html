Expand description

An Observable Queue. The attach_* methods allow a user to use the queue as as a message channel or observe messages passing through. If no consumers are attached, messages will just disappear once they are observed. If no consumers and no observers are attached, then messages will be written into the buffer whenever they are produced. Weak observers can still observe the messages.

NOTE: Due to the needs to ORPC, OQueues should generally implement RefUnwindSafe.

fn attach_producer(&self) -> Result<Box<dyn Producer<T>>, OQueueAttachError>

Attach to the oqueue as a producer. An error represents either that producers are not supported or that producers are supported but all supported producers are already attached (for instance, if a second producer tries to attach to a single-producer oqueue implementation).

Source

fn attach_consumer(&self) -> Result<Box<dyn Consumer<T>>, OQueueAttachError>

Attach to the oqueue as a consumer. An error represents either that producers are not supported or that no more consumers are allowed on this specific oqueue (for example, for a single-consumer oqueue implementation).

Source

fn attach_strong_observer( &self, ) -> Result<Box<dyn StrongObserver<T>>, OQueueAttachError>

Attach to the oqueue as a strong observer. An error represents either that strong observers are not supported or that no more strong-observers are allowed on this specific oqueue (for example, if the oqueue as a limited number of strong-observer slots).

Source

fn attach_weak_observer( &self, ) -> Result<Box<dyn WeakObserver<T>>, OQueueAttachError>

Attach to the oqueue as a weak-observer. An error represents either that weak-observer are not supported or that no more weak-observer are allowed on this specific oqueue (for example, if there are a limited number of weak-observer slots on the oqueue.).
