Collects the RAID-1 member devices named on the kernel command line.

The member disk names are read from the raid.members parameter (see RAID_MEMBERS_PARAM) rather than hardcoded, so the disk layout can be reconfigured from the kernel command-line config (kcmd_configs/*.toml) and tools/qemu_args.sh without touching the kernel. Devices are looked up by name via aster_block::collect_all (the refactored registry keys devices by DeviceId, and virtio disks are auto-named vda, vdb, … in probe order).
