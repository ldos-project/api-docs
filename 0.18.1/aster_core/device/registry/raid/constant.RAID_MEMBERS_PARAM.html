The kernel command-line parameter naming the RAID-1 member disks.

The member disks are configured via raid.members=<name>,<name>,..., a comma-separated list of block device names (e.g. raid.members=vdc,vdd,vde). The list is ordered: the position of each name is used as the member’s logical index. The value is collected during early boot into RAID_MEMBERS by the aster_cmdline registration below.
