Module raid 

Source
Expand description

RAID-1 logical block device assembly.

This module assembles the RAID-1 device from its virtio member disks and registers it with the block layer. The device then gets a devtmpfs node (/dev/raid) like any other block device, so user space can mount a filesystem on it (e.g., mount -t ext2 /dev/raid /raid1).
