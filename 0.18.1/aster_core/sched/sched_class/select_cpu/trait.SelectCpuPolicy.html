fn select_cpu(&self, input: &SelectCpuInput<'_>) -> CpuId

Returns the CPU whose run queue the thread in input joins.

It is called with local IRQs disabled, possibly in interrupt context, and with no run-queue lock held. It must not sleep, block or allocate. Any state the policy needs lives in the policy object. The returned CPU should be in the thread’s affinity mask.
